# LOCATOR
 Locator es una aplicación web desarrollada con Nuxt 3 y TailwindCSS para registrar y gestionar puntos de interés en un mapa interactivo mediante Leaflet. Permite autenticación de usuarios, categorización jerárquica, subida de imágenes y validación colaborativa de ubicaciones. Utiliza Prisma para la gestión de datos y Pinia para el estado global.
